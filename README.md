# assets.maritime.sh

Public static files for Maritime emails and posts, served by GitHub Pages.

- Add a file, commit, push to `main`. It is live at `https://assets.maritime.sh/<path>` in about a minute.
- Email images go in `email/` (for example `email/changelog-015-screens.png`).
- Never delete or rename a file once an email links to it: sent emails keep loading it forever.
- Everything here is public. No private screenshots, customer data or keys.
